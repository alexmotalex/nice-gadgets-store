# Nice Gadgets Store

[DEMO LINK](https://alexmotalex.github.io/nice-gadgets-store/)

A responsive React + TypeScript storefront for mobile devices, tablets, and accessories. This project includes product browsing, category filtering, search, cart management, and favorites.

## Demo

- Live demo: [https://alexmotalex.github.io/nice-gadgets-store/](https://alexmotalex.github.io/nice-gadgets-store/)

## Features

- Catalog browsing by category
- Product detail pages with specifications
- Cart management and item quantity controls
- Favorites list support
- Responsive layout for desktop and mobile
- Search and filter functionality
- Clean UI with animations and image galleries

## Tech Stack

- React
- TypeScript
- Vite
- Sass
- React Router
- Font Awesome
- Bulma

## Scripts

- `npm install` — install dependencies
- `npm start` — run the development server
- `npm run build` — build the app for production
- `npm run lint` — run linters for code and styles
- `npm run format` — format TypeScript files with Prettier
- `npm run deploy` — deploy the app

## Deployment

This app is set up for GitHub Pages deployment. Use:

```bash
npm run deploy
```

## Project structure

- `src/` — application source code
- `public/` — static assets and JSON API mock data
- `package.json` — project dependencies and scripts
